# The Floor

A single-page stick figure that dances hip-hop to music it can hear. Bass drops the bounce, mids pull the arms through a wave or body roll, and brighter hits snap it into a robot. Kick-steps trade off when the low end stays in front.

Three ways to feed it:

- **Drop a beat** plays a short boom-bap loop made in the browser.
- **Listen** reads the microphone. If permission is blocked, the other two sources still work.
- **Play a track** uses an audio file on your machine. The file never leaves the browser.

## Run

```bash
npm install
npm run dev
```

Open http://127.0.0.1:4317.
